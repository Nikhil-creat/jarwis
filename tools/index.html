Live data tools

Free public APIs that give Jarwis assistants real data: GitHub, weather, currency rates, tech news, research papers and Wikipedia. No keys needed.

34 of the 99 assistants can fetch real data before they answer (42 with the optional keyed sources). Open an assistant on the assistants page, tap Fetch live data, and it analyses what comes back. All sources are free and need no API key. They were chosen from the community list public-apis, and APIs that now need a key (for example OpenAlex) were left out.

GitHub API

Public profile and repository facts. Limited to about 60 requests per hour per visitor without a key.

Used by: GitHub Portfolio Curator, Git & GitHub Fixer, Open-Source Maintainer.

Extra sources that need a free key

Three more sources switch on when the site owner adds a free key: Adzuna job search (for Job & Internship Scout, Resume & Career Coach, LinkedIn Profile Optimizer and Interview Prep Coach), Finnhub US stock quotes (for Decision Analyst, Risk Assessor, Scenario Modeler and Cashflow Modeler) and CalorieNinjas nutrition (for Wellness Advisor, Fitness & Habit Coach and Shopping Coordinator). Keys stay on the server and are never sent to your browser. The Status page shows which ones are on.

Good to know

The calls go straight from your browser to each service, so that service can see your IP address. Live data is only as fresh and complete as the source. Weather data by Open-Meteo.com.
